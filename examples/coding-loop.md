# Coding Loop Example

1. Discover project instructions, relevant code/tests and CI failures.
2. Plan the smallest vertical slice.
3. Create an isolated worktree.
4. Implement the approved plan.
5. Run targeted tests/static checks.
6. Independent verifier evaluates the acceptance matrix.
7. Reviewer checks correctness/security/maintainability.
8. Repair blocking findings within budget.
9. Run regression suite.
10. Ship only when mandatory gates pass.
